### What is SABSTCN?
A modular, multi-sensor surveillance system using ESP32 that detects
intrusion, monitors environmental hazards, classifies threat levels (0-5),
sends real-time alerts via MQTT + Telegram, and logs events locally.

### Tech Stack
ESP32 | FreeRTOS | MQTT | Firebase | Python | KiCad | OpenCV | TinyML
